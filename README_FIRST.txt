POSTGRESQL ASSIGNMENT SUBMISSION PACKAGE

1. Open PostgreSQL_Assignment_Report.docx in Microsoft Word. Fill in the bracketed student/course fields on the cover page.
2. Open Evidence/README_Evidence.txt and follow the screenshot checklist. Save screenshots in the Evidence folder.
3. Read PostgreSQL_Commands.txt as a reference appendix. It is not a single executable script; some commands create or delete data and are marked accordingly.
4. Compare the report against your lecturer's original assignment instructions before submitting. Those exact instructions were not available when this package was assembled, so extra rubric-specific requirements may need to be added.
5. Submit the DOCX and any required evidence/backup files in the manner specified by your lecturer or learning platform.
